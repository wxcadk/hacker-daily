SQL 注入：从登录绕过到数据窃取 ⭐⭐ 基础
HIGH SQL注入 Web安全 OWASP
把恶意指令藏在用户输入里，让数据库执行攻击者的命令。用 ' OR '1'='1 绕过登录，用 UNION SELECT 窃取数据。攻击者视角：登录框打个单引号报错就说明有戏，盲注可以逐字符猜出整个数据库。
跨站脚本攻击（XSS）：注入 JavaScript 劫持会话 ⭐⭐ 基础
HIGH XSS Web安全 前端攻击
在网页中注入恶意 JavaScript，让别人的浏览器执行你的代码。反射型藏在 URL 里，存储型存入数据库永久生效。攻击者视角：用 document.cookie 偷走登录凭证，或显示假登录框骗取密码。
